Terms of use
------------
Per https://developers.google.com/workspace/drive/api/guides/branding, no
pre-approval is needed to use the Google Drive logo to show that an app
integrates with Drive. The conditions that bind us:

  * "You can resize the logo, but don't make any other changes to the logo."
  * "Other than the tool tip, don't alter the Google Drive logo in any way."
  * A button carrying the icon needs a tooltip naming the action it performs.
  * "Don't abbreviate the term 'Google Drive.'"

Google publishes no greyed-out or monochrome variant, and dimming the colour
one would be exactly the alteration the guidelines forbid. So the mark appears
only while an account is connected; the signed-out, unavailable and signing-in
states use a neutral cloud glyph drawn by this project instead.

Provenance
----------

Rendering
---------
The file on disk is byte-for-byte as published. One substitution is applied in
memory at render time, in monitor.gui.player_icons._qt_maskable: the SVG uses
an alpha mask, but Qt implements masks as luminance masks only, so the file's
dark mask fill would dim the whole logo to roughly a third of its opacity.
Substituting white for that fill yields the alpha the file asks for, so the
drawn result is the mark exactly as published.
